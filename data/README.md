# Data

Everything the paper's numbers are computed from. Nothing here is generated by the checks; `make corpus` regenerates `suffice/` from `harvest/` in a temporary directory and compares it byte for byte. The terms under which each source's records are redistributed are in `NOTICE.md`.

| Folder | What it is | Size |
|---|---|---|
| `suffice/` | SUFFICE: 1,898 tasks, one JSON file each, under `<domain>/<split>/`, and `manifest.json` | 17 MB |
| `fdaaa/instances/` | the regulation set: 320 tasks whose contract is 42 CFR Part 11 | |
| `fdaaa/external/` | the ClinicalTrials.gov snapshot the regulation set was built from, with `SHA256SUMS.txt`, which also pins the third-party tracker table that is not included | 8 MB |
| `harvest/` | the records of 2026-08-01 that the generators read, reduced to the fields they use: `<domain>/records.jsonl`, the sampling frame of each domain, and `SHA256SUMS.json` | 11 MB |
| `pilot/instances/` | the 62 hand-built tasks of the exploratory pilot (Appendix G) | |
| `pilot/artifacts/` | the sources the hand-built tasks read: open-source Python projects at pinned commits (each keeps its own license file), arXiv titles and abstracts, and public records; each has a `PROVENANCE` file | 10 MB |
| `episode_logs/` | `prime-episode-logs.tar.gz`, every episode log behind the paper and the JSON each analysis script wrote, with `SHA256SUMS.txt`; `make logs` extracts it into `results/` at the repository root | 34 MB |

## SUFFICE

Four domains (`security`, `clinical`, `drugsafety`, `financial`), each built from one public source (see `NOTICE.md`), and seven splits:

| Split | Tasks | Role |
|---|---|---|
| `dev` | 192 | development (families split 40/10/50 into dev, val, and held out, each family whole) |
| `val` | 48 | validation |
| `heldout_balanced` | 480 | held out, balanced diagnostic strata: the confirmatory split (Sections 6.1 and 6.2) |
| `heldout_natural` | 218 | held out, natural prevalence with no rebalancing; not reported in the paper |
| `heldout_onebranch` | 240 | variant: one branch of a conclusion fails |
| `heldout_locator` | 480 | variant: the evidence field is uncertain (Section 6.2) |
| `heldout_text` | 240 | variant: the evidence is free text (Section 6.3) |

The first four splits are the 938 primary tasks; the last three are derived variants. The generators are in `src/suffice/construction/`, the schema and validator in `src/suffice/`, and `docs/GLOSSARY.md` maps the code's names to the paper's terms.

Paths written inside the pilot tasks' notes, and inside the episode logs, are the paths the files had when they were written; `docs/PATH_MAP.md` maps them to this layout.
